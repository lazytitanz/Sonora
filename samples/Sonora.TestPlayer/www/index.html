        What to know
        
            
        
              
          
                
        • Sample-peak limiter. The ceiling is applied to sample values. It does not measure inter-sample (true) peaks, which can exceed the ceiling after D/A conversion or lossy re-encoding.
          • 
                
        • Look-ahead is construction-time. It is set when the limiter is created and cannot be changed here. Only ceiling and release are adjustable at runtime. The value shown is what the controller reports.
          • 
                
        • No metering. This test player does not expose level meters or gain-reduction, so audible checks are manual.
